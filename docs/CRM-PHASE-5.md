# EMDAD HVAC CRM — Phase 5

## Project Operations Foundation

This phase establishes the project as the operational center of the CRM.

### Assignment history
Every project assignment and reassignment is preserved in `project_assignment_history`.

### Project timeline
`crm_project_timeline` unifies project creation, activities, and collection events into a chronological reporting surface.

### Notifications
An active-target uniqueness constraint prevents duplicate unread attention notifications for the same notification type, project, and employee.

No static KPI or mock operational data is introduced.
