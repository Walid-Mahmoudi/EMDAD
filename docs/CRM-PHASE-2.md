# EMDAD HVAC CRM — Phase 2

## Reporting foundation

Phase 2 adds database-backed reporting views for project financials and employee performance.

### `crm_project_financials`
- Expected value
- Probability
- Weighted value
- Actual contract value
- Required collection
- Collected amount
- Outstanding amount
- Collection percentage

### `crm_employee_performance`
- Project count
- Active/won/lost projects
- Pipeline and weighted pipeline
- Contract value
- Collected and outstanding value
- Activity count
- Overdue follow-ups

All values are derived from CRM tables; no KPI values are hard-coded.
