# EMDAD CRM Production Release

This repository is the production source for the EMDAD CRM.

Production URL: https://emdad-crm.vercel.app

The CRM is designed for EMDAD central-air-conditioning sales operations and includes administration, employees, companies, contacts, projects, sales pipeline, activities, contracts, collections, KPIs, reports, bilingual UI, RTL/LTR, responsive layout, and action popups.
